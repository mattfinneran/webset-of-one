# The Webset of One

A personal demo for the Exa Strategic AE interview process, built with Exa's own Search API.

- **[thewebsetofone.com](https://thewebsetofone.com)** — the landing page: a mock Webset result with exactly one verified row (Matt Finneran), enriched with sales record, technical proof, and everything else.
- **[/territory](https://thewebsetofone.com/territory.html)** — the work sample: a 25-account East Coast territory plan researched with 56 live Exa queries — dated AI signals with sources, buying committees, why-Exa wedges, discovery openers, and a flattened contact webset.

## How it was built

Research ran through Exa's MCP server (`web_search_advanced_exa`), orchestrated by Claude agents.
Static HTML, no build step. Deployed on Vercel (`matt-exa-territory`), domains `thewebsetofone.com`
and `mattshouldworkforexa.com`.

Not an official Exa property. Built by Matt Finneran · mattfinneran@gmail.com
