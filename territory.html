Methodology

Research was run through Exa's MCP server (web_search_advanced_exa), the same neural search API Exa sells, orchestrated by Claude agents across 56 live queries. Each account got targeted queries for AI initiatives, platform builds, hiring signals, and named AI leadership; only publicly verifiable facts with sources made the cut. Tiering reflects signal strength and wedge clarity, not company size. The contact webset lists names and titles from public record; direct contact details are enriched privately per sequence and stay off the public page.
